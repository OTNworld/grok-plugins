# Contributing

This is the public Grok CLI marketplace source for OTNworld plugins.

- Open an **issue** for bugs and ideas.
- External drive-by PRs may be closed; maintainers land changes after review.
- Do not commit `node_modules`, `.env`, or `fleet.yaml`.
- Plugin code changes should include `npm test` under `plugins/grok-build-worker/mcp`.
